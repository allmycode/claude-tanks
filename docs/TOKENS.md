# Расход токенов

Сколько токенов ушло на создание проекта. Посчитано по журналу сессии Claude Code
(`~/.claude/projects/.../58ece9c6-....jsonl`): для каждого обращения к модели в журнале записано поле `usage`,
значения просуммированы по каждому запросу пользователя. Повторяющиеся записи одного и того же ответа учтены один раз.

- Модель: Claude Opus 5.5 (`claude-opus-5-5`), все 67 обращений.
- Период: 22.10.2026 20:49 — 23.10.2026 08:39 (МСК).
- Сабагенты не запускались, весь расход — в одной сессии.
- Последняя строка таблицы — этот запрос; он посчитан только до момента записи файла.

## Итого

| Категория | Токенов |

| Вход без кэша | 134 |
| Запись в кэш | 528 480 |
| Чтение из кэша | 11 479 575 |
| **Вход всего** | **12 008 189** |
| **Выход (ответы и код)** | **140 285** |

Почему вход так велик: при каждом обращении модель заново получает весь разговор (инструкции, код, результаты инструментов).
Почти всё это берётся из кэша — такие токены обрабатываются и тарифицируются значительно дешевле обычного входа.
Собственно написанное моделью — 140 тыс. выходных токенов.
