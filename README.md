# Танки

Игра «Танки» с видом сверху: одиночная игра, вдвоём за одним компьютером и по сети.

## Без сети

Откройте `index.html` в браузере.

## Сетевая игра

1. Установите зависимости (один раз) и запустите сервер:

   ```bash
   npm install
   npm start
   ```

   Сервер слушает порт 8081 (другой порт: переменная окружения `PORT`) и печатает адреса, по которым к нему можно подключиться.

2. Каждый игрок открывает игру — либо по адресу сервера в браузере (`http://<адрес>:8081`), либо локальный `index.html` — и выбирает в меню **ПО СЕТИ**, указав адрес сервера, например `192.168.1.67:8081`.

3. Первый подключившийся ждёт второго, после чего игра начинается. Если пар больше, сервер сам раскидывает их по отдельным комнатам.

Игра считается на сервере; клиенты отправляют нажатия клавиш и рисуют полученное состояние.
Для игры через интернет порт сервера нужно открыть наружу (проброс порта на роутере или облачный сервер).

## Настройки сервера

Файл `config.json` рядом с `server.js` (другой путь — переменная окружения `TANKS_CONFIG`). Сейчас в нём задаётся процент выпадения каждого бонуса:

```json
{
  "powerups": {
    "helmet": 15.88,
    "star": 20.6,
    "grenade": 15.88,
    "clock": 15.88,
    "shovel": 15.88,
    "tank": 15.88
  }
}
```

| Ключ | Бонус |
| --- | --- |
| `helmet` | каска — неуязвимость |
| `star` | звезда — прокачка танка |
| `grenade` | граната — уничтожает врагов на поле |
| `clock` | часы — враги замирают |
| `shovel` | лопата — бетонная стена вокруг штаба |
| `tank` | танк — дополнительная жизнь |

- Значения — проценты, в сумме обычно 100. Если сумма другая, они пересчитываются пропорционально (то есть работают как веса).
- `0` или отсутствующий в файле бонус не выпадает.
- Файл перечитывается при старте каждой новой игры: правки действуют без перезапуска сервера, на уже идущую игру — нет.
- Ошибки в файле (неверный JSON, отрицательные числа, неизвестные бонусы) сервер пишет в консоль; при неверном JSON или нулевой сумме используются значения по умолчанию. Итоговые проценты сервер печатает при запуске и при каждом изменении файла.
- Настройки действуют на сетевую игру. Одиночная игра и игра вдвоём за одним компьютером идут в браузере без сервера и используют значения по умолчанию (звезда около 20,6%, остальные около 15,9%).

## Файлы

- `game.js` — логика игры, общая для браузера и сервера
- `stages.js` — 35 уровней оригинальной Battle City (данные из [feichao93/battle-city](https://github.com/feichao93/battle-city), MIT)
- `index.html` — отрисовка, звук, управление, меню и сетевой клиент
- `server.js` — HTTP-сервер для файлов игры и WebSocket-комнаты на двух игроков
- `config.json` — настройки сервера (проценты выпадения бонусов)
- [docs/PLAN.md](docs/PLAN.md) — задание и как оно менялось
- [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md) — детали реализации и сетевой протокол
- [docs/TOKENS.md](docs/TOKENS.md) — сколько токенов ушло на создание проекта
